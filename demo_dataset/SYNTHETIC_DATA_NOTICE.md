# SYNTHETIC DATA NOTICE

All data in this directory and its subdirectories is **100% synthetic** (artificially generated).

- Person names, phone numbers, account numbers, and vehicle registration numbers are fabricated.
- FIR (First Information Report) texts are generated from templates and do not represent real incidents.
- CDR (Call Detail Record) and transaction data are randomly generated with seeded randomness for reproducibility.
- Locations mentioned are real Indian city landmarks used only as geographic references.

## Purpose

This synthetic dataset enables **deterministic demo runs** of the Criminal Network Analysis system without requiring real case data or internet connectivity.

## ⚠️ WARNING

**DO NOT replace this synthetic data with real FIRs, CDRs, or transaction records in a public repository.**

See [PII_POLICY.md](../PII_POLICY.md) for the full data handling policy.
